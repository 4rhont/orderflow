ORDERFLOW
Pet project for study. Backend service made for order processing of local shop.
Tech stack: C#, .NET 10, ASP.NET Core, PostgreSQL, Entity Framework Core, xUnit.

-

Current status: Initial setup.

To be realised features: 
- REST API for managing products and orders.
- PostgreSQL integration using Entity Framework Core.
- Database schema and EF Core migrations.
- Order creation with stock availability checks.
- Inventory reservation and release on order cancellation.
- Order status management and transition validation.
- Transaction handling to prevent overselling.
- Input validation and consistent error responses.
- Unit and integration tests using xUnit.
- API documentation with OpenAPI.
- Docker Compose for local deployment.
- CI pipeline using GitHub Actions.
